Avatar Chat マニュアル

OpenAI互換のLLMとおしゃべりすると、返事の内容に合わせてアバターの表情が変わるチャットです。このマニュアルは start.bat と同じフォルダに入っています。

1. Avatar Chat とは

  • 表情が変わる … 返事のたびにLLMが気持ち(うれしい・かなしい…)を選び、その表情の画像に切り替わります。
  • キャラごとの記憶 … 会話から覚えておくべきことを自動でメモし、時間とともに薄れていきます。キャラ同士では共有されません。
  • キャラを増やせる … 好きな画像で自分のキャラを追加できます(7・8章)。
  • ネット検索・天気 … 必要なときだけ調べて答えます(6章。Brave検索のAPIキーが必要)。
  • 5か国語の画面 … 日本語・English・简体中文・Español・Português。
  • 自分のPCだけで動く … 会話・記憶は自分のPC内(user-data)に保存されます。外に出るのは、LLMへの送信(自分のサーバーなら外に出ません)と、ネット検索を使ったときの検索語だけです。

2. 起動と終了

はじめて起動する

  1. start.bat をダブルクリックします。黒い画面が開き、初回だけ Python などを自動でダウンロードします(インターネット接続が必要。数分かかります)。
  2. 続いて「ローカルLLMのセットアップ」のメニューが出ます。数字キーを押すだけで選べます。
    選択どんなとき
    1 RadeonAMDのグラフィックカード。Vulkan版のllama.cppを入れます。IntelのGPUや内蔵GPUでも動くかもしれません(未確認です。内蔵GPUはメモリを共有するため、遅くなったり動かなかったりすることがあります)。
    2 GeForce RTX 20系以降NVIDIAのグラフィックカード(VRAM 8GB以上)。CUDA版を入れます。
    3 すでにLLMサーバーがあるLM Studio・Ollama・llama.cppなどを使う人。接続先だけ登録します(サーバー自体は入れません)。
    4 あとで設定する今は何もしない。あとで「設定」画面で自分で入力します。
    メニューの上に、お使いのグラフィックカード名が表示されます。迷ったらそれを見て選んでください。
  3. 1・2を選ぶと、llama.cpp・llama-swap・モデル(Stheno v3.4 8B、約4.9GB)を自動でダウンロードします。サーバーに負担をかけないよう、モデルはわざとゆっくり(約17分)ダウンロードします。黒い画面は閉じないでください。閉じても、次に start.bat を開けば続きから再開します。
    2つ目のモデル(Lumimaid v0.2 8B)も入れるか聞かれます。迷ったら「1 いいえ」でOKです。
    注意: Stheno も Lumimaid も、すでに少し古いモデルで、日本語は弱めです(言い回しが不自然になったり、文がおかしくなったりすることがあります)。VRAM 8GB で動かせる範囲での割り切りです。日本語の質を上げたい場合は、より大きなモデルや、ほかのモデルに llama-swap\config.yaml で差し替えてください(VRAM が足りないと動きません)。
  4. 終わるとブラウザが自動で開き、チャット画面が出ます。開かないときは、ブラウザで http://127.0.0.1:8765 を開いてください。
2回目からはメニューは出ません。start.bat をダブルクリックするだけです(LLMサーバーも一緒に起動します)。

終了する

  • アプリの黒い画面(start.bat の画面)を閉じます。
  • セットアップで入れたLLMサーバー(llama-swap)は別の小さなウィンドウ(タスクバーに最小化)で動いています。使い終わったらそちらも閉じてください(閉じるとGPUのメモリが空きます)。
  • 会話中にいきなり閉じても、直前までの会話は保存され、まだ記憶に整理されていない分は次回起動時に整理されます。

セットアップをやり直したい

misc フォルダの setup-llm.bat をダブルクリックします(同じメニューが出ます)。ダウンロード済みのファイルは再利用されます。

3. 画面の見かた

左:キャラ一覧キャラを選ぶ/＋キャラ追加/言語の切り替え/設定
中央:会話上にアバターと名前、下に会話ログと入力欄。入力欄の横で検索のモードを選べます。
右:記憶そのキャラが覚えていること。バーが短いほど忘れかけています。

会話する

  • 下の入力欄に書いて送信ボタン(またはEnter)で送ります。改行はShift+Enter。
  • 返事が来るとアバターの表情が変わります。しばらくすると元の表情(ふつう)に戻ります。
  • 返事が遅いときは「…」が出ています。モデルを読み込む最初の1回は特に時間がかかります。
  • キャラが記憶を思い出して返事したときは、会話の下に「思い出したこと」が薄く表示されます。

ボタン

ボタンはたらき
会話を消すそのキャラとの会話ログを消します。消す前に、まだ覚えていない内容を記憶に整理するので、記憶は残ります。
キャラ削除自分で追加したキャラだけに出ます。会話と記憶もすべて消え、元に戻せません。組み込みキャラ(もち・ほのか・レイ)は削除できません。
右の記憶の「×」その記憶ひとつを消します。まちがって覚えてしまったときに使います。

左下の設定ボタンで開きます。変更したら保存を押します。

5. 記憶のしくみ

  • 数回話すごとに、LLMが「覚えておくべきこと」(名前・好み・約束など)を取り出してメモします。
  • メモには重要度(1〜5)がつきます。重要なほど長く残ります。
  • 時間がたつと強さ(バーの長さ)が下がります。でも話題に出て思い出されるたびに、強くなり、忘れにくくなります。
  • 強さが小さくなりすぎた記憶は、思い出されなくなります。
  • 記憶はキャラごとに分かれています。「もち」に話したことを「ほのか」は知りません。
  • タブを閉じる・「会話を消す」・次回起動時にも、整理しきれていない会話は自動で記憶に整理されます。

覚え間違いは右の記憶の「×」で消せます。

6. ネット検索と天気

最新の話題や、知らないことを聞かれたとき、ネットを検索して答えに使えます。

  1. Brave Search API(外部サイト)でAPIキーを取得します。
  2. 設定 → Brave Search APIキー に貼り付けて保存します。
  3. 入力欄の横のメニューでモードを選びます。
    • 🔍 自動 … 必要だとキャラが判断したときだけ検索(既定)。
    • 🔍 毎回 … 毎回検索。
    • 🔍 なし … 検索しない。
  • キーが未設定のときは、メニューが「🔍 キー未設定」になります。クリックすると設定画面が開きます。
  • 検索したときは、会話の下に「検索した語」と出典のリンクが表示されます。
  • 日本の地名つきの天気の質問(例:「明日の福岡の天気は?」)は、検索ではなく気象庁の公式データで答えます(英語などでも可)。検索モードが「なし」でないときに働きます。現在の画面の仕様では、Brave Search APIキーを設定していないと検索モードが使えず、天気もこの機能は働きません(天気の取得そのものにはキー代は不要です)。
プライバシー検索を使うと、検索語が Brave に送られます。会話の全文は送られません。

7. キャラを追加する

  1. 左の＋キャラ追加を押します。
  2. 次を入力します。
    項目書くこと
    名前必須。
    性格・口調の設定キャラの人格の元になります。書き方は8章。
    最初のあいさつ省略可。キャラ選択時、最初に表示されます。
    アバターの動き方「生き物・デフォルメ」か「人間型」(違い)。
    表情画像neutral(ふつう)は必須。ほかは省略可。足りない表情はneutralで代わりに表示されます。
  3. 追加を押すと、キャラ一覧に増えます。

追加したキャラは user-data\characters に保存されます。削除はそのキャラを選んでキャラ削除です。

まず neutral だけで試す最初は neutral の1枚だけで追加して、動きを確かめてから、ほかの表情を足していくのがおすすめです。画面からの追加は新規作成のみで、あとから画像を差し替えるにはキャラを作り直すか、ファイルを直接置き換えます。

8. アバターの作り方

アバターは「表情ごとの画像」を入れ替えて見せているだけです。絵が描ける人も、画像生成AIを使う人も、同じ手順で自分のキャラを作れます。

画像の仕様

項目内容
形式PNG・JPEG・WebP など(画面から追加するとき)。SVGは画面からは追加できません(ファイルで置く場合のみ可)。
背景透過(背景なし)がおすすめ。背景つきでも使えますが、四角い枠が見えます。
大きさ自動で長辺768px以内のWebPに変換されます(縮小のみ。小さい画像は拡大されません)。表示は高さ300px程度なので、512〜768px四方もあれば十分です。
枚数neutral必須+最大7枚(計8表情)。
向き・構図全身でも上半身でも可。ただし表示が小さいので、顔がはっきり見える構図にしてください。

8つの表情

LLMは、次の説明を見て「今の返事にはどの表情が合うか」を選びます。

名前日本語使われる場面
neutralふつう(必須)落ち着いた会話。ふだんの顔。
happyうれしいうれしい・楽しい・ほめられた。
sadかなしい悲しい・残念・落ち込んだ。
angryおこる怒り・不満・ぷんぷん。
surprisedおどろく驚き・予想外のこと。
embarrassedてれる照れ・恥ずかしい。
thinkingかんがえる考え込む・迷う。返事を待っている間にも出ます。
sleepyねむい眠い・のんびり・退屈。

全部そろえなくても動きますが、neutral・happy・sad の3つがあると印象がだいぶ変わります。

作るときのコツ

  • 同じ人に見えることが一番大事です。表情ごとに顔立ち・髪型・服が変わると、別人に見えてしまいます。
  • 画像生成AIで作る場合
    • まず neutral を1枚決めます。
    • ほかの表情は、同じシード・同じプロンプトのまま、表情に関する言葉(笑顔・泣き顔・怒り顔など)だけを差し替えて生成します。
    • もっと安定させたいときは、neutral を元画像にして、変化を弱めに(元画像を強く残す設定で)画像→画像で作ります。
    • 生成のたびに、顔・髪・服・リボンなどの小物が変わっていないか確認し、変なものが写り込んだ画像は作り直します。
  • 絵を描く場合 … neutral を描いてから、目・眉・口だけを描き替えるのが楽です。全表情で同じキャンバスサイズにします。
  • 背景の透過 … 背景が単色になるよう生成/描画して、切り抜きツール(画像編集ソフトの「背景を削除」など)で透過PNGにします。
  • キャンバスと足元をそろえる … 表情ごとにキャラの大きさや位置がずれると、切り替えたときにアバターが跳ねて見えます。全表情で同じ大きさのキャンバス、同じ位置にしてください。アバターは足元を支点に動くので、足元(下端)を揃えるのが大切です。
  • 権利に注意 … 他人が描いた絵や、利用条件のあるモデル・素材は、そのルールに従ってください。公開・配布するときは特に確認を。

動き方の選び方

種類動き向いているキャラ
生き物・デフォルメ(squash)つぶれたり伸びたりして、はずみます。うれしいときは跳ねます。マスコット・動物・不思議な生き物。
人間型(soft)体は歪めず、上下とごく小さな傾きだけ。人間のキャラ。

人間の絵を「生き物」にすると、体がぐにゃっと歪んで不自然に見えます。人間型にしてください。動きが邪魔なときは、設定のアバターの動きで切れます。

性格設定の書き方

「性格・口調の設定」は、そのままLLMに渡されます。短く具体的に書くほど、小さなモデルでも安定します。組み込みキャラ(characters フォルダの character.json)が見本になります。

  • 基本情報 … 年齢・一人称・あなた(相手)への気持ち。
  • 話し方 … 口癖や語尾、例文を3〜4個。例文が一番効きます。
  • ふるまい(箇条書き) … 例:「返事は1〜3文」「聞かれたことに答える。同じ言葉を繰り返さない」「わからないことは素直に『知らない』と言う」。
  • 表情のきっかけ … 例:「本気で褒められたら照れる」と書くと、embarrassed が出やすくなります。
例:のんびり屋の謎の生き物。一人称は「ぼく」。語尾に「〜もち」を付ける。
【話し方】ゆっくり、やさしく。例: 「おはようもち」「それはすてきもち」
【ふるまい】
- 返事は1〜3文。
- 聞かれたことに答える。同じ言葉を繰り返さない。
- 褒められると照れる。

ファイルで作る(上級)

画面からでは足りないとき(SVG画像を使う、表情を8つ以外に増やす、設定を直すなど)は、フォルダとファイルを直接作れます。

  1. user-data\characters の中に、好きな名前(英数字)のフォルダを作ります。例: user-data\characters\sakura
  2. そこに表情画像(png / webp / svg など)と character.json を置きます。
  3. ブラウザを再読み込みします(F5)。
{
  "name": "さくら",
  "persona": "のんびりした18歳の女の子。…",
  "greeting": "こんにちは。来てくれたんだね。",
  "motion": "soft",
  "fallback": "neutral",
  "emotions": {
    "neutral": { "file": "neutral.webp", "hint": "ふつうの状態。落ち着いた会話" },
    "happy":   { "file": "happy.webp",   "hint": "うれしい・楽しい・褒められた" },
    "sad":     { "file": "sad.webp",     "hint": "悲しい・残念・落ち込んだ" }
  }
}
  • motion は soft(人間型)か squash(既定)。
  • fallback は、該当する表情がないときに使う表情(通常は neutral)。
  • hint は「この表情をどんなときに使うか」の説明で、LLMがこれを読んで選びます。書き換えると、そのキャラだけ表情の出方を変えられます。省略すると標準の説明が使われます。
  • 表情名を8つ以外に増やすこともできます(例: shy)。その場合は hint を必ず書いてください。
  • 編集前に、user-data をバックアップしておくと安心です(10章)。JSONの , や " を間違えると、そのキャラが一覧から消えます。

9. 言語の切り替え

左下の言語メニューで、日本語・English・简体中文・Español・Português を選べます。切り替えると次のものが変わります。

  • 画面の文字、エラーなどのメッセージ。
  • 組み込みキャラ(もち・ほのか・レイ)の名前・性格・あいさつ。
  • キャラの返事の言語(その言語で返事するよう指示します)。

自分で追加したキャラの名前・設定・あいさつは、書いた言語のままです。

注意
  • 英語・中国語・スペイン語・ポルトガル語の画面と組み込みキャラの翻訳は機械翻訳で、ネイティブの確認はしていません。不自然な表現があるかもしれません。
  • モデルによって得意な言語が違います。Stheno などの小型モデルは、英語が最も安定します。日本語は弱めです。
  • 言語を切り替えても、すでにある会話ログの言語は変わりません。
  • このマニュアルは日本語・English・简体中文・Español・Português の5言語です(上のタブで切り替え)。翻訳は機械翻訳です。

フォルダ / ファイル中身消すと

misc\downloads\ダウンロードしたzipの置き場消してOK(容量が空きます)。

バックアップ

アプリを閉じてから、user-data フォルダを丸ごとコピーします。戻すときは、同じ場所に上書きコピーします。

更新する

  1. 新しい zip を展開します。
  2. 中の app・characters・misc フォルダと start.bat・manual.htmlを、今のフォルダに上書きコピーします。
  3. start.bat で起動します。

user-data・system・models などは zip に入っていないので、上書きしても消えません。

11. 困ったとき

症状確認すること
「モデル名を設定画面で…」と出る設定 のモデル名が空です。「一覧を取得」で選んで保存してください。
返事が来ない/「接続できない」などのエラーLLMサーバーが起動していますか。セットアップした場合は、タスクバーに小さな llama-swap のウィンドウがあるか確認。なければ start.bat をもう一度。LM Studio・Ollama は先にそれぞれを起動します。接続先URL が合っているかも確認してください。
最初の返事がとても遅い最初の1回はモデルをGPUに読み込むため、数十秒かかります。2回目以降は速くなります。
いつも遅い/途中で止まるGPUのメモリ不足かもしれません。ほかのアプリ(ゲーム・画像生成など)を閉じる、設定の履歴の往復数を減らす、llama-swap\config.yaml の -c 8192 を -c 4096 にする、を試してください。
返事の形式が崩れる、同じことを繰り返す温度を 0.5〜0.7 に下げる。それでも直らないときは別のモデルを試します。アプリ側でも、崩れた返事は読み取り直しと再試行をします。

Avatar Chat Manual

A chat app where you talk with an OpenAI-compatible LLM and the avatar's expression changes to match each reply. This manual is in the same folder as start.bat.

1. What is Avatar Chat?

  • Expressions change … With every reply the LLM picks a feeling (happy, sad…) and the avatar switches to the matching image.
  • Memory per character … Things worth remembering are noted automatically from your chats and fade over time. Characters do not share memories.
  • Add your own characters … Use any images you like (chapters 7 and 8).
  • Web search and weather … Looks things up only when needed (chapter 6; a Brave Search API key is required).
  • Interface in 5 languages … 日本語, English, 简体中文, Español, Português.
  • Runs on your PC only … Chats and memories are saved on your PC (user-data). The only things that leave it are what is sent to the LLM (nothing leaves if it is your own server) and the search words when you use web search.

  2. Next, the "Local LLM setup" menu appears. Just press a number key.

Quitting

  • Close the app's black window (the start.bat window).
  • The LLM server installed by the setup (llama-swap) runs in a separate small window (minimized to the taskbar). Close that one too when you are done (closing it frees the GPU memory).
  • Even if you close it suddenly mid-chat, the conversation up to that point is saved, and anything not yet turned into memories is processed at the next start.

Redoing the setup

Double-click setup-llm.bat in the misc folder (the same menu appears). Files already downloaded are reused.

5. How memory works

  • Every few exchanges, the LLM picks out "things worth remembering" (names, preferences, promises…) and takes notes.
  • Each note gets an importance (1–5). The more important, the longer it lasts.
  • As time passes the strength (bar length) drops. But each time it comes up in conversation and is recalled, it gets stronger and harder to forget.
  • A memory whose strength has dropped too low is no longer recalled.
  • Memories are kept per character. What you told Mochi, Honoka does not know.
  • When you close the tab, use "Clear chat", or start the app again, any conversation not yet organized is automatically turned into memories.

Wrong memories can be removed with the "×" on the right.

8. Making an avatar

The avatar is simply swapping between "one image per expression". Whether you draw by hand or use an image-generation AI, the steps are the same.

Image specs

ItemDetails
FormatPNG, JPEG, WebP, etc. (when adding from the screen). SVG cannot be added from the screen (only when you place files directly).
BackgroundTransparent (no background) is recommended. Images with a background also work, but a rectangular frame will be visible.
SizeAutomatically converted to WebP with the long side within 768 px (only reduced; small images are not enlarged). It is displayed about 300 px tall, so 512–768 px square is plenty.
NumberNeutral (required) + up to 7 more (8 expressions in total).
FramingFull body or upper body both work. Since it is displayed small, make sure the face is clearly visible.

The 8 expressions

The LLM reads the descriptions below and chooses "which expression fits this reply".

NameMeaningWhen it is used
neutralNeutral (required)Calm conversation. The everyday face.
happyHappyGlad, having fun, being praised.
sadSadSad, disappointed, down.
angryAngryAnger, dissatisfaction, pouting.
surprisedSurprisedSurprise, something unexpected.
embarrassedEmbarrassedShy, bashful.
thinkingThinkingDeep in thought, hesitating. Also shown while waiting for a reply.
sleepySleepySleepy, relaxed, bored.

It works without a full set, but having neutral, happy and sad makes a big difference to the impression.

Tips for making them

  • Looking like the same person matters most. If the face, hairstyle or clothes change between expressions, they look like different people.
  • With an image-generation AI
    • First settle on one neutral image.
    • For the other expressions, keep the same seed and same prompt and swap only the words about the expression (smiling, crying, angry face, etc.).
    • For even more stability, use neutral as the source image and do image-to-image with a weak change (a setting that keeps the source strongly).
    • Each time, check that the face, hair, clothes, ribbons and other small items have not changed, and regenerate any image where something odd appears.
  • If you draw … Draw neutral first, then redraw only the eyes, eyebrows and mouth; that is easiest. Use the same canvas size for all expressions.
  • Transparent background … Generate/draw so the background is a single color, then make a transparent PNG with a cut-out tool (such as "remove background" in image editors).
  • Match the canvas and the feet … If the character's size or position differs between expressions, the avatar seems to jump when switching. Use the same canvas size and the same position for all expressions. The avatar moves around its feet, so aligning the feet (bottom edge) is important.
  • Mind the rights … Follow the rules for art drawn by others and for models or materials that have terms of use. Check especially when you publish or distribute.

Choosing a motion style

TypeMotionGood for

Writing the personality

"Personality and speech style" is passed to the LLM as it is. The shorter and more concrete it is, the more stable even a small model becomes. The built-in characters (character.json in the characters folder) are good examples.

  • Basics … Age, how it refers to itself, feelings toward you.
  • Way of speaking … Verbal tics and sentence endings, plus 3–4 example lines. Examples work best.
  • Behavior (bullet points) … e.g. "Replies are 1–3 sentences", "Answer what is asked; do not repeat the same words", "If it doesn't know, honestly say so".
  • Expression triggers … e.g. writing "gets embarrassed when sincerely praised" makes embarrassed appear more often.
Example: A laid-back, mysterious creature. Calls itself "I". Ends sentences with "-mochi".

[Behavior]

- Answer what is asked. Do not repeat the same words.

Using files (advanced)

When the screen is not enough (using SVG images, having more than the 8 expressions, fixing settings, etc.), you can create the folder and files directly.

  1. In user-data\characters, create a folder with any name you like (letters and digits). Example: user-data\characters\sakura
  2. Put the expression images (png / webp / svg, etc.) and a character.json in it.
  3. Reload the browser (F5).
{
  "name": "Sakura",
  "persona": "A laid-back 18-year-old girl. …",
  "greeting": "Hello. You came, didn't you.",
  "motion": "soft",
  "fallback": "neutral",
  "emotions": {
    "neutral": { "file": "neutral.webp", "hint": "Normal state. Calm conversation" },
    "happy":   { "file": "happy.webp",   "hint": "Glad, having fun, praised" },
    "sad":     { "file": "sad.webp",     "hint": "Sad, disappointed, down" }
  }
}
  • motion is soft (human) or squash (default).
  • fallback is the expression used when the matching one is missing (normally neutral).
  • hint describes "when to use this expression", and the LLM reads it to choose. Rewriting it changes how expressions appear for that character only. If omitted, the standard description is used.
  • You can have expression names other than the 8 (e.g. shy). In that case always write a hint.
  • It is safest to back up user-data before editing (chapter 10). A mistake with a , or " in the JSON makes that character disappear from the list.

9. Switching language

Use the language menu at the bottom left to choose 日本語, English, 简体中文, Español or Português. Switching changes the following.

  • The text on the screen and messages such as errors.
  • The names, personalities and greetings of the built-in characters (Mochi, Honoka, Rei).
  • The language of the character's replies (the character is instructed to reply in that language).

The name, settings and greeting of a character you added stay in the language you wrote them in.

Notes
  • The English, Chinese, Spanish and Portuguese screens and the built-in character translations are machine-translated and have not been checked by native speakers. Some phrasing may sound unnatural.
  • Different models are good at different languages. Small models such as Stheno are most stable in English. Japanese is on the weak side.
  • Switching language does not change the language of existing chat logs.
  • This manual is available in Japanese, English, Chinese, Spanish and Portuguese (see the tabs at the top); the translations are also machine-made.

    "sad": "sad, teary eyes",
    "angry": "angry, furrowed brow",
    "surprised": "surprised, wide eyes, open mouth",
    "embarrassed": "embarrassed, blush, looking away",
    "thinking": "thinking, hand on own chin, looking up",
    "sleepy": "sleepy, half-closed eyes"
  }
}
  • base is the look shared by all expressions, and variants are the words added per expression. Not changing seed and base keeps the face consistent (Tips for making them).
  • To change only the expression from one reference image, add "init_image": "reference.png" and "denoise": 0.6 (the smaller the denoise, the closer to the original). To vary it per expression, use "variant_denoise": {"sad": 0.7}.
  • The transparency step assumes a plain white background. Put white background in base.
  • Each image takes tens of seconds. If one is not finished after 5 minutes, that expression results in an error.
  • The ComfyUI workflow is built automatically as a basic single-model setup (checkpoint → KSampler → save). LoRA and ControlNet cannot be used.

Avatar Chat 使用手册

这是一款与兼容 OpenAI 的 LLM 聊天的应用,头像的表情会随着回复内容而变化。本手册与 start.bat 位于同一文件夹中。

1. Avatar Chat 是什么

  • 表情会变化 … 每次回复时,LLM 会选择一种心情(开心、难过……),头像随之切换为对应表情的图片。
  • 每个角色各有记忆 … 会自动记下对话中值得记住的内容,并随时间逐渐淡忘。角色之间不共享记忆。
  • 可以增加角色 … 可以用喜欢的图片添加自己的角色(第 7、8 章)。
  • 联网搜索・天气 … 仅在需要时查询并作答(第 6 章。需要 Brave 搜索的 API 密钥)。
  • 5 种语言的界面 … 日本語・English・简体中文・Español・Português。
  • 只在自己的电脑上运行 … 对话和记忆保存在自己的电脑中(user-data)。会传到外部的只有发送给 LLM 的内容(如果是自己的服务器则不会外传),以及使用联网搜索时的搜索词。

5. 记忆的原理

  • 每聊几次,LLM 就会提取“值得记住的内容”(名字、喜好、约定等)并记成笔记。
  • 每条笔记都有重要度(1~5)。越重要,保留得越久。
  • 随着时间推移,强度(进度条长度)会下降。但每当在话题中被想起,就会变强,更不容易被忘记。
  • 强度变得太小的记忆将不会再被想起。
  • 记忆是按角色区分的。你对 Mochi 说过的话,Honoka 并不知道。
  • 关闭标签页、点击“清除对话”或下次启动时,尚未整理完的对话也会自动整理成记忆。

记错的内容可以用右侧记忆上的“×”删除。

8. 制作头像

头像其实只是切换“每种表情一张图片”。无论是手绘的人还是使用图像生成 AI 的人,步骤都相同,都能制作自己的角色。

图片规格

项目内容
格式PNG、JPEG、WebP 等(从界面添加时)。SVG 无法从界面添加(只能用文件放置)。
背景推荐透明(无背景)。带背景的图片也能用,但会看到方形边框。
大小会自动转换为长边不超过 768px 的 WebP(只缩小,小图不会被放大)。显示高度约 300px,所以 512~768px 见方就足够了。
数量neutral 必填 + 最多 7 张(共 8 种表情)。
朝向・构图全身或半身均可。但因为显示得较小,请使用脸部清晰可见的构图。

8 种表情

LLM 会根据下面的说明,选择“哪种表情适合当前的回复”。

名称中文使用场合
neutral平静(必填)平静的对话。平时的表情。
happy开心高兴、愉快、被夸奖。
sad难过悲伤、遗憾、沮丧。
angry生气愤怒、不满、气鼓鼓。
surprised惊讶惊讶、意料之外的事。
embarrassed害羞害羞、不好意思。
thinking思考陷入沉思、犹豫。等待回复期间也会显示。
sleepy困倦困了、悠闲、无聊。

不必凑齐也能运行,但有 neutral、happy、sad 这 3 张,印象会大不相同。

制作要点

  • 看起来是同一个人最重要。如果每个表情的五官、发型、服装都不同,就会像是不同的人。
  • 用图像生成 AI 制作时
    • 先确定一张 neutral。
    • 其他表情保持相同的种子(seed)和相同的提示词,只替换与表情相关的词(笑脸、哭脸、生气的脸等)来生成。
    • 想要更稳定时,以 neutral 为原图,用较弱的变化幅度(强烈保留原图的设置)进行图生图。
    • 每次生成后,请检查脸、头发、服装、缎带等小物件是否有变化,如果出现奇怪的东西,就重新生成。
  • 手绘时 … 先画好 neutral,然后只重画眼睛、眉毛和嘴巴会比较轻松。所有表情使用相同的画布尺寸。
  • 背景透明 … 生成/绘制时让背景为单一颜色,再用抠图工具(图像编辑软件的“删除背景”等)做成透明 PNG。
  • 统一画布和脚下位置 … 如果各表情中角色的大小或位置有偏差,切换时头像看起来会跳动。请让所有表情使用相同大小的画布、相同的位置。头像以脚下为支点运动,所以对齐脚下(下边缘)很重要。
  • 注意版权 … 他人绘制的图画,以及有使用条件的模型・素材,请遵守其规则。公开・分发时尤其要确认。

如何选择动作方式

类型动作适合的角色
生物 / Q版(squash)会被压扁、拉长,有弹性地跳动。高兴时会蹦起来。吉祥物・动物・神秘生物。
人形(soft)身体不变形,只有上下移动和非常轻微的倾斜。人类角色。

如果把人物画选成“生物”,身体会被扭曲,看起来不自然。请选“人形”。动作碍事时,可以在设置的 头像动作 中关闭。

性格设定的写法

“性格与说话方式”会原样传给 LLM。写得越简短具体,即使是小模型也越稳定。内置角色(characters 文件夹中的 character.json)可以作为范例。

  • 基本信息 … 年龄、自称、对你(对方)的感情。
  • 说话方式 … 口头禅和句尾,以及 3~4 个例句。例句最有效。
  • 行为准则(条目式) … 例如:“回复 1~3 句”“回答被问到的问题,不要重复同样的话”“不知道的事就老实说‘不知道’”。
  • 表情的触发点 … 例如写上“被真心夸奖会害羞”,就更容易出现 embarrassed。
示例:悠闲的神秘生物。自称“我”。句尾加“~mochi”。
【说话方式】慢悠悠、温柔。例:“早上好 mochi”“那真棒 mochi”
【行为准则】
- 回复 1~3 句。
- 回答被问到的问题。不要重复同样的话。
- 被夸奖会害羞。

用文件制作(进阶)

界面无法满足需求时(使用 SVG 图片、增加 8 种以外的表情、修改设置等),可以直接创建文件夹和文件。

  1. 在 user-data\characters 中创建一个任意名称(英文字母和数字)的文件夹。例如:user-data\characters\sakura
  2. 在其中放入表情图片(png / webp / svg 等)和 character.json。
  3. 刷新浏览器(F5)。
{
  "name": "樱",
  "persona": "悠闲的 18 岁女孩。……",
  "greeting": "你好。你来啦。",
  "motion": "soft",
  "fallback": "neutral",
  "emotions": {
    "neutral": { "file": "neutral.webp", "hint": "平常的状态。平静的对话" },
    "happy":   { "file": "happy.webp",   "hint": "高兴、愉快、被夸奖" },
    "sad":     { "file": "sad.webp",     "hint": "悲伤、遗憾、沮丧" }
  }
}
  • motion 为 soft(人形)或 squash(默认)。
  • fallback 是没有对应表情时使用的表情(通常为 neutral)。
  • hint 是“在什么情况下使用这个表情”的说明,LLM 会读取它来选择。改写后,可以只改变该角色的表情出现方式。省略时使用标准说明。
  • 表情名也可以增加到 8 个以外(例如 shy)。这种情况下请务必写上 hint。
  • 编辑前最好先备份 user-data(第 10 章)。如果 JSON 中的 , 或 " 写错,该角色会从列表中消失。

9. 切换语言

通过左下角的语言菜单,可以选择 日本語、English、简体中文、Español、Português。切换后,以下内容会改变。

  • 界面文字,以及错误等提示信息。
  • 内置角色(Mochi、Honoka、Rei)的名字、性格和问候。
  • 角色回复的语言(会指示角色用该语言回复)。

自己添加的角色的名字、设定和问候,仍保持书写时的语言。

注意
  • 英语、中文、西班牙语、葡萄牙语的界面以及内置角色的翻译均为机器翻译,没有经过母语者的确认。可能会有不自然的表达。
  • 不同的模型擅长的语言不同。Stheno 等小型模型在英语上最稳定。日语较弱。
  • 切换语言不会改变已有对话记录的语言。
  • 本手册提供日语、英语、中文、西班牙语、葡萄牙语版本(见顶部的标签),译文同样是机器翻译。

Manual de Avatar Chat

Un chat en el que hablas con un LLM compatible con OpenAI y la expresión del avatar cambia según el contenido de cada respuesta. Este manual está en la misma carpeta que start.bat.

1. ¿Qué es Avatar Chat?

  • Las expresiones cambian … En cada respuesta el LLM elige un estado de ánimo (feliz, triste…) y el avatar cambia a la imagen de esa expresión.
  • Memoria por personaje … Anota automáticamente lo que conviene recordar de la conversación y se va desvaneciendo con el tiempo. Los personajes no comparten recuerdos.
  • Puedes añadir personajes … Con las imágenes que quieras (capítulos 7 y 8).
  • Búsqueda web y clima … Consulta solo cuando hace falta (capítulo 6; se necesita una clave de API de Brave Search).
  • Interfaz en 5 idiomas … 日本語, English, 简体中文, Español, Português.
  • Funciona solo en tu PC … Las conversaciones y los recuerdos se guardan en tu PC (user-data). Solo salen de él lo que se envía al LLM (nada, si es tu propio servidor) y las palabras de búsqueda cuando usas la búsqueda web.

5. Cómo funciona la memoria

  • Cada pocos intercambios, el LLM extrae «lo que conviene recordar» (nombres, gustos, promesas…) y lo anota.
  • Cada nota recibe una importancia (1–5). Cuanto más importante, más tiempo se conserva.
  • Con el tiempo baja la fuerza (la longitud de la barra). Pero cada vez que sale en la conversación y se recuerda, se refuerza y cuesta más olvidarla.
  • Un recuerdo cuya fuerza ha bajado demasiado deja de recordarse.
  • Los recuerdos están separados por personaje. Lo que le cuentas a Mochi, Honoka no lo sabe.
  • Al cerrar la pestaña, usar «Borrar chat» o en el siguiente inicio, la conversación que no se haya organizado se convierte automáticamente en recuerdos.

Los recuerdos equivocados se pueden borrar con la «×» de la derecha.

6. Búsqueda web y clima

Cuando te preguntan por temas recientes o cosas que no conoce, el personaje puede buscar en la web y usar los resultados en su respuesta.

  1. Obtén una clave de API en Brave Search API (sitio externo).
  2. Pégala en ⚙ Ajustes → Clave de Brave Search API y guarda.
  3. Elige el modo en el menú junto al cuadro de entrada.
    • 🔍 Auto … Busca solo cuando el personaje considera que hace falta (por defecto).
    • 🔍 Siempre … Busca en cada mensaje.
    • 🔍 No … No busca.
  • Si no hay clave, el menú muestra «🔍 Sin clave». Al hacer clic se abre la pantalla de Ajustes.
  • Cuando se ha buscado, bajo el mensaje aparecen las palabras buscadas y los enlaces de las fuentes.
  • Las preguntas sobre el clima que incluyen un lugar de Japón (p. ej. «¿Qué tiempo hará mañana en Fukuoka?») se responden con los datos oficiales de la Agencia Meteorológica de Japón en lugar de una búsqueda (también en español y otros idiomas). Funciona cuando el modo de búsqueda no es «No». Con el diseño actual de la pantalla, sin clave de Brave Search API no se puede usar el modo de búsqueda y esta función del clima tampoco funciona (obtener el clima en sí no cuesta nada).

8. Crear un avatar

El avatar consiste simplemente en intercambiar «una imagen por expresión». Tanto si sabes dibujar como si usas una IA de generación de imágenes, los pasos son los mismos.

Especificaciones de imagen

ElementoDetalle
FormatoPNG, JPEG, WebP, etc. (al añadir desde la pantalla). El SVG no se puede añadir desde la pantalla (solo colocándolo como archivo).
FondoSe recomienda transparente (sin fondo). Con fondo también funciona, pero se verá un marco rectangular.
TamañoSe convierte automáticamente a WebP con el lado largo de 768 px como máximo (solo se reduce; las imágenes pequeñas no se amplían). Se muestra con unos 300 px de alto, así que 512–768 px por lado son más que suficientes.
CantidadNeutral (obligatoria) + hasta 7 más (8 expresiones en total).
Orientación y encuadreCuerpo entero o medio cuerpo. Como se muestra pequeño, usa un encuadre en el que la cara se vea con claridad.

Las 8 expresiones

El LLM lee las descripciones siguientes y elige «qué expresión encaja con la respuesta actual».

NombreSignificadoCuándo se usa
neutralNeutral (obligatoria)Conversación tranquila. La cara de siempre.
happyFelizAlegría, diversión, recibir un elogio.
sadTristeTristeza, decepción, desánimo.
angryEnfadadoEnfado, disgusto, estar de morros.
surprisedSorprendidoSorpresa, algo inesperado.

Funciona sin tener todas, pero contar con neutral, happy y sad cambia bastante la impresión.

Consejos para crearlas

  • Que parezca la misma persona es lo más importante. Si la cara, el peinado o la ropa cambian de una expresión a otra, parecerán personas distintas.
  • Si usas una IA de generación de imágenes
    • Primero decide una imagen neutral.
    • Para las demás expresiones, mantén la misma semilla (seed) y el mismo prompt y cambia solo las palabras relativas a la expresión (sonriendo, llorando, cara de enfado, etc.).
    • Para más estabilidad, usa la neutral como imagen original y genera con imagen a imagen con un cambio débil (con un ajuste que conserve mucho la original).
    • En cada generación, comprueba que no hayan cambiado la cara, el pelo, la ropa ni objetos pequeños como lazos, y rehaz cualquier imagen en la que aparezca algo raro.
  • Si dibujas … Dibuja la neutral y luego redibuja solo los ojos, las cejas y la boca; es lo más cómodo. Usa el mismo tamaño de lienzo para todas las expresiones.
  • Fondo transparente … Genera o dibuja con el fondo de un solo color y conviértelo en un PNG transparente con una herramienta de recorte (como «quitar fondo» de los editores de imagen).
  • Igualar el lienzo y los pies … Si el tamaño o la posición del personaje varían entre expresiones, el avatar parece dar un salto al cambiar. Usa el mismo tamaño de lienzo y la misma posición en todas las expresiones. El avatar se mueve con los pies como punto de apoyo, por lo que es importante alinear los pies (el borde inferior).
  • Ojo con los derechos … Respeta las reglas de los dibujos de otras personas y de los modelos o materiales con condiciones de uso. Compruébalo especialmente al publicar o distribuir.

Elegir el estilo de movimiento

TipoMovimientoIdeal para
Criatura / chibi (squash)Se aplasta y se estira, y rebota. Salta cuando está feliz.Mascotas, animales, criaturas misteriosas.
Humano (soft)No deforma el cuerpo; solo sube/baja y una inclinación mínima.Personajes humanos.

Si eliges «criatura» para un dibujo de una persona, el cuerpo se deforma y queda poco natural. Usa «Humano». Si el movimiento estorba, puedes desactivarlo con Movimiento del avatar en Ajustes.

Cómo escribir la personalidad

«Personalidad y forma de hablar» se pasa tal cual al LLM. Cuanto más breve y concreto, más estable resulta incluso con un modelo pequeño. Los personajes integrados (character.json en la carpeta characters) sirven de modelo.

  • Datos básicos … Edad, cómo se refiere a sí mismo, sentimientos hacia ti.
  • Forma de hablar … Muletillas y terminaciones de frase, y 3–4 frases de ejemplo. Los ejemplos son lo que más funciona.
  • Comportamiento (en viñetas) … p. ej.: «Responde en 1–3 frases», «Contesta lo que se le pregunta; no repite las mismas palabras», «Si no lo sabe, dice con sinceridad que no lo sabe».
  • Detonantes de expresión … p. ej.: si escribes «se avergüenza cuando lo elogian de verdad», aparecerá más a menudo embarrassed.
Ejemplo: Una criatura misteriosa y tranquila. Se llama a sí misma «yo». Termina las frases con «-mochi».
[Forma de hablar] Despacio y con dulzura. Ej.: «Buenos días, mochi» «Qué bonito, mochi»
[Comportamiento]
- Responde en 1-3 frases.
- Contesta lo que se le pregunta. No repite las mismas palabras.
- Se avergüenza cuando la elogian.

  2. Coloca allí las imágenes de expresión (png / webp / svg, etc.) y un character.json.
  3. Recarga el navegador (F5).

  "persona": "Una chica tranquila de 18 años. …",

  • motion es soft (humano) o squash (por defecto).
  • fallback es la expresión que se usa cuando falta la correspondiente (normalmente neutral).
  • hint es la descripción de «cuándo usar esta expresión»; el LLM la lee para elegir. Si la reescribes, solo cambia cómo aparecen las expresiones en ese personaje. Si se omite, se usa la descripción estándar.
  • También puedes tener nombres de expresión distintos de los 8 (p. ej. shy). En ese caso escribe siempre un hint.
  • Conviene hacer una copia de seguridad de user-data antes de editar (capítulo 10). Si te equivocas con una , o un " del JSON, ese personaje desaparecerá de la lista.

9. Cambiar de idioma

Con el menú de idioma de abajo a la izquierda puedes elegir 日本語, English, 简体中文, Español o Português. Al cambiar, se modifica lo siguiente.

  • Los textos de la pantalla y los mensajes como los errores.
  • El nombre, la personalidad y el saludo de los personajes integrados (Mochi, Honoka, Rei).
  • El idioma de las respuestas del personaje (se le indica que responda en ese idioma).

El nombre, la configuración y el saludo de los personajes que añadas se quedan en el idioma en que los escribiste.

Atención
  • Las pantallas en inglés, chino, español y portugués y las traducciones de los personajes integrados son traducción automática y no han sido revisadas por hablantes nativos. Puede haber expresiones poco naturales.
  • Cada modelo domina distintos idiomas. Los modelos pequeños como Stheno son más estables en inglés. El japonés es más débil.
  • Cambiar de idioma no modifica el idioma de los registros de conversación existentes.
  • Este manual está disponible en japonés, inglés, chino, español y portugués (consulta las pestañas de arriba); las traducciones también son automáticas.

Manual do Avatar Chat

Um chat em que você conversa com um LLM compatível com OpenAI e a expressão do avatar muda conforme o conteúdo de cada resposta. Este manual fica na mesma pasta que o start.bat.

1. O que é o Avatar Chat

  • As expressões mudam … A cada resposta, o LLM escolhe um sentimento (feliz, triste…) e o avatar troca para a imagem dessa expressão.
  • Memória por personagem … Anota automaticamente o que vale a pena lembrar das conversas, e isso vai esmaecendo com o tempo. Os personagens não compartilham memórias.
  • Você pode adicionar personagens … Com as imagens que quiser (capítulos 7 e 8).
  • Pesquisa na web e clima … Consulta apenas quando necessário (capítulo 6; é preciso uma chave de API do Brave Search).
  • Interface em 5 idiomas … 日本語, English, 简体中文, Español, Português.
  • Funciona só no seu PC … As conversas e memórias ficam salvas no seu PC (user-data). O que sai dele é apenas o que é enviado ao LLM (nada, se for o seu próprio servidor) e os termos de busca quando você usa a pesquisa na web.

5. Como a memória funciona

  • A cada poucas trocas, o LLM extrai "o que vale a pena lembrar" (nomes, gostos, promessas…) e faz anotações.
  • Cada anotação recebe uma importância (1–5). Quanto mais importante, mais tempo ela dura.
  • Com o tempo, a força (o comprimento da barra) diminui. Mas, cada vez que ela surge na conversa e é lembrada, fica mais forte e mais difícil de esquecer.
  • Uma memória cuja força caiu demais deixa de ser lembrada.
  • As memórias são separadas por personagem. O que você conta ao Mochi, a Honoka não sabe.
  • Ao fechar a aba, usar "Limpar conversa" ou na próxima inicialização, a conversa ainda não organizada é transformada automaticamente em memórias.

Memórias erradas podem ser apagadas com o "×" à direita.

8. Criar um avatar

O avatar nada mais é do que a troca de "uma imagem por expressão". Seja você quem desenha ou quem usa uma IA de geração de imagens, os passos são os mesmos.

Especificações da imagem

Dicas para criar

  • Parecer a mesma pessoa é o mais importante. Se o rosto, o penteado ou a roupa mudarem de uma expressão para outra, parecerão pessoas diferentes.
  • Se usar uma IA de geração de imagens
    • Primeiro defina uma imagem neutra.
    • Para as outras expressões, mantenha a mesma seed e o mesmo prompt e troque apenas as palavras sobre a expressão (sorrindo, chorando, cara de raiva etc.).
    • Para ficar ainda mais estável, use a neutra como imagem original e gere com imagem para imagem com uma mudança fraca (com uma configuração que preserve bastante a original).
    • A cada geração, confira se o rosto, o cabelo, a roupa, o laço e outros itens pequenos não mudaram, e refaça qualquer imagem em que apareça algo estranho.
  • Se for desenhar … Desenhe a neutra e depois redesenhe só os olhos, as sobrancelhas e a boca; é o mais fácil. Use o mesmo tamanho de tela em todas as expressões.
  • Fundo transparente … Gere/desenhe com o fundo de uma cor só e transforme em PNG transparente com uma ferramenta de recorte (como "remover fundo" dos editores de imagem).
  • Alinhar a tela e os pés … Se o tamanho ou a posição do personagem variarem entre as expressões, o avatar parece pular ao trocar. Use o mesmo tamanho de tela e a mesma posição em todas as expressões. O avatar se move tendo os pés como ponto de apoio, por isso é importante alinhar os pés (a borda inferior).
  • Atenção aos direitos … Respeite as regras de desenhos feitos por outras pessoas e de modelos ou materiais com condições de uso. Confira especialmente ao publicar ou distribuir.

Como escrever a personalidade

"Personalidade e jeito de falar" é repassado ao LLM exatamente como escrito. Quanto mais curto e concreto, mais estável fica, mesmo com um modelo pequeno. Os personagens integrados (character.json na pasta characters) servem de modelo.

  • Informações básicas … Idade, como se refere a si mesmo, sentimentos em relação a você.
  • Jeito de falar … Cacoetes e finais de frase, e 3–4 frases de exemplo. Os exemplos são o que mais funciona.
  • Comportamento (em tópicos) … ex.: "Responde em 1–3 frases", "Responde o que foi perguntado; não repete as mesmas palavras", "Se não sabe, diz com sinceridade que não sabe".
  • Gatilhos de expressão … ex.: se você escrever "fica envergonhada quando é elogiada de verdade", embarrassed aparecerá com mais frequência.
Exemplo: Uma criatura misteriosa e tranquila. Refere-se a si mesma como "eu". Termina as frases com "-mochi".
[Jeito de falar] Devagar e com ternura. Ex.: "Bom dia, mochi" "Que lindo, mochi"
[Comportamento]
- Responde em 1-3 frases.
- Responde o que foi perguntado. Não repete as mesmas palavras.
- Fica envergonhada quando é elogiada.

Usando arquivos (avançado)

Quando a tela não basta (usar imagens SVG, ter mais que as 8 expressões, corrigir configurações etc.), você pode criar a pasta e os arquivos diretamente.

  1. Dentro de user-data\characters, crie uma pasta com o nome que quiser (letras e números). Exemplo: user-data\characters\sakura
  2. Coloque nela as imagens de expressão (png / webp / svg etc.) e um character.json.
  3. Recarregue o navegador (F5).
{
  "name": "Sakura",
  "persona": "Uma garota tranquila de 18 anos. …",
  "greeting": "Olá. Você veio, né.",
  "motion": "soft",
  "fallback": "neutral",
  "emotions": {
    "neutral": { "file": "neutral.webp", "hint": "Estado normal. Conversa tranquila" },
    "happy":   { "file": "happy.webp",   "hint": "Alegria, diversão, elogios" },
    "sad":     { "file": "sad.webp",     "hint": "Tristeza, decepção, desânimo" }
  }
}
  • motion é soft (humano) ou squash (padrão).
  • fallback é a expressão usada quando a correspondente não existe (normalmente neutral).
  • hint é a descrição de "quando usar esta expressão"; o LLM a lê para escolher. Reescrevendo-a, você muda a forma como as expressões aparecem só nesse personagem. Se omitida, usa-se a descrição padrão.
  • Também é possível ter nomes de expressão além das 8 (ex.: shy). Nesse caso, escreva sempre um hint.
  • É mais seguro fazer backup de user-data antes de editar (capítulo 10). Se errar uma , ou um " no JSON, esse personagem some da lista.

9. Trocar o idioma

No menu de idioma, no canto inferior esquerdo, você pode escolher 日本語, English, 简体中文, Español ou Português. Ao trocar, mudam as seguintes coisas.

  • Os textos da tela e mensagens como os erros.
  • O nome, a personalidade e a saudação dos personagens integrados (Mochi, Honoka, Rei).
  • O idioma das respostas do personagem (ele é instruído a responder nesse idioma).

O nome, as configurações e a saudação dos personagens que você adicionou continuam no idioma em que foram escritos.

Atenção
  • As telas em inglês, chinês, espanhol e português e as traduções dos personagens integrados são tradução automática e não foram revisadas por falantes nativos. Pode haver expressões artificiais.
  • Cada modelo é bom em idiomas diferentes. Modelos pequenos como o Stheno são mais estáveis em inglês. O japonês é mais fraco.
  • Trocar o idioma não muda o idioma dos históricos de conversa já existentes.
  • Este manual está disponível em japonês, inglês, chinês, espanhol e português (veja as abas no topo); as traduções também são automáticas.

Gerar automaticamente as imagens de expressão (gen_images.py → make_sprites.py)

Este é o fluxo para criar de uma vez as 8 expressões de um mesmo personagem. É preciso que o ComfyUI esteja em execução e tenha um modelo instalado.

  1. Crie um arquivo de especificação (JSON). Copie o exemplo abaixo e ajuste.
  2. Informe o endereço do ComfyUI pela variável de ambiente COMFY_HOST (se não estiver definida, http://127.0.0.1:8188).
    set COMFY_HOST=http://127.0.0.1:8188
  3. Execute %py% misc\gen_images.py especificacao.json. Ele cria uma imagem por expressão e salva em outdir como nome_da_expressao.png. Para refazer apenas algumas expressões, acrescente-as no final separadas por vírgula (ex.: especificacao.json sad,happy).
  4. Com %py% misc\make_sprites.py pasta_PNG pasta_saida você obtém WebPs com fundo transparente. Essa conversão remove as informações embutidas no PNG, como o prompt.
  5. Registre os WebPs resultantes pela tela Adicionar personagem.
{
  "outdir": "misc/gen/mychar",
  "prefix": "avt_mychar",
  "checkpoint": "nome_do_arquivo_do_modelo.safetensors",
  "width": 832, "height": 1216, "steps": 28, "cfg": 5.5, "seed": 12345,
  "base": "1girl, solo, long hair, white blouse, upper body, simple background, white background",
  "negative": "worst quality, low quality, bad anatomy, text, watermark",
  "variants": {
    "neutral": "closed mouth, light smile",
    "happy": "bright smile, open mouth",
    "sad": "sad, teary eyes",
    "angry": "angry, furrowed brow",
    "surprised": "surprised, wide eyes, open mouth",
    "embarrassed": "embarrassed, blush, looking away",
    "thinking": "thinking, hand on own chin, looking up",
    "sleepy": "sleepy, half-closed eyes"
  }
}
  • base é a aparência comum a todas as expressões e variants são as palavras acrescentadas em cada uma. Não mudar seed nem base mantém o rosto coerente (Dicas para criar).
  • Para mudar apenas a expressão a partir de uma imagem de referência, acrescente "init_image": "referencia.png" e "denoise": 0.6 (quanto menor o denoise, mais parecido com o original). Para variar por expressão, use "variant_denoise": {"sad": 0.7}.
  • O processo que torna o fundo transparente pressupõe um fundo branco liso. Coloque white background em base.
  • Cada imagem leva dezenas de segundos. Se passados 5 minutos ainda não terminou, essa expressão dá erro.
  • O fluxo de trabalho do ComfyUI é montado automaticamente com uma configuração básica de um só modelo (checkpoint → KSampler → salvar). LoRA e ControlNet não podem ser usados.

Criar o zip de distribuição (make_zip.py)

Cria, a partir da pasta do projeto, um zip sem user-data (conversas e configurações), system, downloads, llama.cpp, llama-swap, models e a pasta de trabalho gen. O destino é avatar-chat-dist\avatar-chat.zip, um nível acima do projeto. Para colocar em outro lugar, acrescente o destino no final (ex.: %py% misc\make_zip.py C:\temp\a.zip).

Verificar o funcionamento (smoke_test.py)

Copia o projeto para uma pasta temporária, inicia o aplicativo com um LLM de mentira e testa, uma a uma, as APIs que a tela usa. Se no final aparecer RESULT: ALL PASSED, deu certo. Não mexe no seu user-data. Serve para conferir depois de corrigir o código.

AtençãoEstes scripts foram feitos e executados no ambiente do autor (Linux). Nem todos foram realmente testados com o system\python do Windows. Se algo não funcionar, investigue a partir da mensagem de erro.
